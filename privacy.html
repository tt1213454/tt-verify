隐私政策（Privacy Policy）

TT数据看板（以下简称"本应用"）重视你的隐私。本政策说明当我们获得你的 TikTok 账号授权时，如何处理相关数据。

1. 我们收集的信息

在你明确授权后，我们通过 TikTok 官方 Display API 获取：账号公开视频列表，以及每条视频的观看量、点赞量、评论量、分享量等公开计数。我们不收集你的密码、私信、好友关系或其他非公开个人信息。

2. 信息的使用

所收集数据仅用于在你的看板中展示视频指标与趋势分析，不会用于任何其他目的。

3. 数据的存储

数据存储在你可控的环境中。访问令牌用于维持授权状态，可随时通过撤销授权终止。

4. 数据共享

我们不会将你的数据出售或分享给第三方。

5. 撤销授权

你可以随时在 TikTok 账号的授权管理页面中撤销对本应用的授权。撤销后，我们将停止获取新数据。

6. 联系我们

如有任何隐私相关问题，请通过应用内提供的联系方式与我们联系。
